# EaseBus — Smart Business Management Suite

Welcome to **EaseBus**, an enterprise-grade business management suite built for sales, inventory, order processing, delivery tracking, customer management, expenses, and financial intelligence.

## Running the Application Locally

1. **Place in Apache Webroot:** Ensure the files are placed inside `d:\xampp\htdocs\EaseBus\` (or `d:\xampp\htdocs\businessM\`).
2. **Start Apache & MySQL:** Start Apache and MySQL from the XAMPP Control Panel.
3. **Launch Browser:** Access the application by opening your browser to:
   ```
   http://localhost/EaseBus/
   ```
